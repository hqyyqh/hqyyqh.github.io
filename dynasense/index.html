面向 LS-DYNA 的 VS Code 扩展

让 K 文件编辑顺手起来。

面向 LS-DYNA 的开源免费 VS Code 扩展，支持本地离线使用。

✓100% 离线可用·✓本地安全解析·✓开源免费

按字段编辑

直接按字段修改，或在关键字管理器中编辑卡片，再应用回 K 文件。

  • ✦
    字段选中与替换Tab / Shift+Tab 切换字段，选中后直接输入新值
  • ✦
    字段标尺与网格对照字段位置和列宽，查看卡片中的参数排列
  • ✦
    卡片表单编辑在管理器中查看字段说明、修改数值，点击应用写回文件

直达手册章节

无需在数千页 PDF 中反复翻找。从当前关键字打开对应章节，参数定义、公式与中英对照就在代码旁。

  • ✦
    字段悬停提示查看字段名称、类型和取值说明，并打开相关帮助
  • ✦
    手册章节定位从关键字打开对应章节，在编辑器旁查阅正文、公式与图片
  • ✦
    外部 PDF 跳转从帮助入口打开本地 PDF，查看对应手册内容

查找定义与对象引用

从文件层级、关键字索引或对象引用出发，找到需要修改的卡片。

  • ✦
    引用文件树沿主文件与 Include 层级浏览，打开引用的文件
  • ✦
    关键字索引按关键字浏览模型卡片，点击条目定位代码
  • ✦
    对象定义与引用按对象 ID 查找定义与引用位置，在相关卡片间跳转
